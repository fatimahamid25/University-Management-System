# University Management System (UMS)

A web-based University Management System developed to streamline and manage essential university operations through a centralized platform.

## Project Overview

The University Management System (UMS) is designed to simplify academic and administrative tasks by providing an organized platform for managing university-related information.

The system integrates multiple management modules with a centralized MySQL database to support efficient data handling and accessibility.

## Key Features

- **Authentication:** Secure user login and session management.
- **Dashboard:** Overview of university operations and records.
- **Student Management:** Manage student information and records.
- **Applicant Management:** Handle admission applicant information.
- **Department Management:** Manage university departments.
- **Program Management:** Organize academic programs.
- **Attendance Management:** Record and manage student attendance.
- **Database Integration:** Centralized data storage using MySQL.

## Installation and Setup

### Prerequisites

- XAMPP
- PHP
- MySQL
- Web Browser

### Steps

1. Clone the repository:

   ```bash
   git clone https://github.com/fatimahamid25/University-Management-System.git
   ```

2. Move the project folder into the XAMPP `htdocs` directory.

3. Start Apache and MySQL from the XAMPP Control Panel.

4. Create a database using phpMyAdmin.

5. Import the provided SQL database file.

6. Configure the database credentials in `db.php`.

7. Open the following URL in your browser:

   ```text
   http://localhost/University-Management-System/
   ```
